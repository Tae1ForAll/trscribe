## Project Overview

- a CLI tool to generate srt, vtt, and ass files from video or audio (mp3, mp4, wav and so on)
- tech stack mainly includes Open AI whisper, and other necessary dependencies

## Project Structure & Architecture

- `src/`: main application source code.
- `tests/`: test functions

## Rules & Tooling

- **package management**: pip to add dependencies (ask for a confirmation before adding)

## Data handling

- Ensure all input data is strictly validated using Pydantic Models before processing
